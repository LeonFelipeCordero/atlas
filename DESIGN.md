# Design

A light workspace for engineers mapping unfamiliar code at their desk. Restrained color: plum-tinted neutrals with a muted plum accent for actions, selection, and graph structure. Small green dots signal an imported snapshot, not an automatically current index.

System sans typography, monospace only for CLI commands and signatures. Rounded shadcn buttons, inputs, and badges. Repository rows instead of repeated cards. Thin borders separate regions; graph nodes use soft 12px corners.

The project workspace has a persistent left-hand file and folder navigator. Full path breadcrumbs establish location above separate Map and Report work areas for the current scope. Expanded navigator branches stay open across work-area changes. Folders navigate at any depth; single-child folder chains use compact path labels. Map contains only structure and connections, with a collapsible contents and connection inspector below the canvas. Initial graph zoom favors readable labels; the fit-view control provides an explicit full overview. Report contains recorded complexity, size, dependency metrics, cycles, and index diagnostics, with explicit links back to the relevant map scope. Conventional test files stay hidden. Outgoing dependencies outside the current scope use dashed outlines and explicit Outside scope labels. Outside-repository references and outside-scope test dependencies are excluded. Indexed boundary folders/files can be explored, and boundary functions navigate to their containing file with the function selected. On narrow screens a Project disclosure reveals the same navigator, and Report flows in one column. Motion is limited to state feedback and disabled with reduced-motion preferences.

The `dashboard/src/styles.css` entry imports tokens and base styles from `dashboard/src/styles/base.css`, graph styles from `dashboard/src/styles/graph.css`, responsive rules from `dashboard/src/styles/responsive.css`, and the project navigator and work-area layout from `dashboard/src/styles/project-workspace.css`. Graph behavior lives in `dashboard/src/components/graph/`.
