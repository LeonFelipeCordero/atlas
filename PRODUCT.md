# Product

## Register

product

## Users and purpose

Engineers exploring unfamiliar code during ordinary daytime development. Atlas helps them understand internal dependencies in a repository, starting with an adaptive folder overview and drilling through folders at any depth, files, and functions.

## Scope

Register repository metadata, index local sources on demand directly into SQLite through the Python service, and explore the latest graph. No jobs, authentication, AI, cloning, or generated documentation. Keep the database and UI small and maintainable.

## Personality

Friendly, calm, precise. Light surfaces, muted plum accents, rounded controls, and familiar navigation. The graph is the main workspace, not a decorative dashboard.

## Principles

Show location through full path breadcrumbs, not fixed depth levels. Compact single-child folder chains without skipping meaningful branches or direct files. Keep indexing instructions next to the repository. Make graph direction and aggregation legible. Preserve disconnected nodes; never imply the index proves something is unused. Hide conventional test files from graph views. Keep the current scope primary, with one-hop outgoing in-repository dependencies outside it shown as labelled boundary nodes. Exclude outside-repository references and outside-scope test dependencies. Allow navigation to indexed boundary targets without expanding their dependencies in place. Keep a searchable list and a focused connection inspector.

## Anti-references

No brutalist borders, neon terminals, ornamental dashboards, large metric cards, or modal-first workflows. No automatic indexing or freshness promises.

## Accessibility

Keyboard-accessible navigation and controls, labelled graph nodes, a contents-list alternative to canvas navigation, visible focus, reduced motion, responsive stacking, and actionable loading/error/empty states.
