Usage: atlas mutations [OPTIONS]

  Derive independent JSON byte-edit manifests, never change source or save
  results. Opt in via atlas.json: mutations.rules is a list of rule IDs.
  Default/empty lists generate nothing. --rules lists exact language coverage.
  Conditions, unary operators and unlisted aliases are excluded. Syntactic
  support is not type validity.

Options:
  -f, --f, --folder PATH  [default: .]
  --saved                 Read persisted candidates for this folder; reject
                          stale sources instead of refreshing
  --rules                 Show the versioned rule catalog and limitations
                          instead of generating
  --help                  Show this message and exit.
