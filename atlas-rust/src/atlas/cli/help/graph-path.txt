Usage: atlas graph path [OPTIONS] FROM TO

  Print a shortest discovered route, or its bounded-search failure status.

Options:
  --max-depth INTEGER RANGE  [default: 6; 0<=x<=20]
  --max-edges INTEGER RANGE  [default: 100; 1<=x<=1000]
  --max-nodes INTEGER RANGE  [default: 30; 1<=x<=300]
  --relations TEXT           [default: CALLS,REFERENCES]
  --direction [out|in|both]  [default: out]
  --help                     Show this message and exit.
