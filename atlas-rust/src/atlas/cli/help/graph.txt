Usage: atlas graph [OPTIONS] COMMAND [ARGS]...

  Read an indexed graph as JSON; unresolved targets are not classified as
  external. Stable keys retain their indexed spelling.

Options:
  --project TEXT   Registered project name or ID; defaults to the indexed
                   folder containing the current directory.
  --revision TEXT  Expected graphRevision; reject a stale graph.
  --help           Show this message and exit.

Commands:
  children  Print a page of direct children using key, limit, and offset...
  context   Print bounded breadth-first graph context around a stable key.
  find      Print ranked node matches for a name, path, or stable key, up...
  overview  Print graph counts and bounded root nodes for the selected...
  path      Print a shortest discovered route, or its bounded-search...
  show      Print node details and bounded ancestors for an indexed...
  source    Fetch verified excerpts for one or more keys; limits apply...
